2. **Commented-out code**: Removed from main.py and anthropic_client.py
3. **Magic strings**: Created `PricingStatus` enum with values like `NOT_AVAILABLE`, `NOT_FOUND_ON_MAIN_PAGE`, etc.
4. **Generic exceptions**: Created exception hierarchy; all `except Exception` replaced with specific types
5. **Raw dict**: `extract_company_data()` now returns `CompanyExtractionData` typed model instead of `Optional[dict]`
6. **Deprecated imports**: `List[str]` → `list[str]`
7. **Unused imports**: Removed `os`, `Anthropic`, `DataExtractionError`
8. **Unnecessary async**: `load_domains()` converted to sync function
9. **Magic numbers**: `3` and `50` moved to `MAX_PRICING_URLS` and `DEFAULT_IMPORT_LIMIT` in config
