- `src/services/` - Business logic services
- `src/models/` - Data models and enums
- `src/utils/` - Config, exceptions, helpers, logger
- `src/llm_prompts/` - LLM prompt templates

Updated `pyproject.toml` for src layout:
```toml

[tool.ruff]

[tool.pyright]
```

**Before** (mixed concerns):
```python
class AnthropicClient:
    async def extract_company_data(self, html, url) -> tuple[bool, data, error]:
        cleaned = self._clean_html(html)
        prompt = f"..."  # inline prompt
        response = await self._call_api(prompt)
        data = self._parse_response(response)
```

**After** (separated):

`src/clients/anthropic_client.py` - Pure API client:
```python
class AnthropicClient:
    async def send_message(self, prompt: str, max_retries: int = 3) -> str:
        """Send prompt to Anthropic, return response text or raise exception."""
```

`src/services/extraction_service.py` - Business logic:
```python
class ExtractionService:
    async def extract_company_data(self, html: str, url: str) -> tuple[bool, CompanyExtractionData | None, str | None]:
        cleaned = clean_html(html)
        prompt = build_company_extraction_prompt(url=url, content=cleaned, ...)
        response = await self.client.send_message(prompt)
        data = parse_company_response(response, url)
        return (True, data, None)
```
