## Implementation

### 1. BatchScraperService Extraction

**New `services/batch_scraper.py`:**
- `BatchScraperService.__init__()` - Sets up clients with semaphores
- `scrape_domains()` - Orchestrates parallel scraping, returns `BatchScrapingResult`
- `_process_results()` - Filters exceptions from raw results
- `_count_pricing_extracted()` - Counts valid pricing results
- `save_results()` - Saves to JSON file

**New `models.py` addition:**
```python
class BatchScrapingResult(BaseModel):
    results: list[ScrapingResult]
    total: int
    successful: int
    failed: int
    pricing_extracted: int
    elapsed_seconds: float
```

**Simplified `main.py`:**
```python
async def main() -> None:
    # Load config
    api_key = os.getenv("ANTHROPIC_API_KEY")
    domains = load_domains(DOMAIN_LIST_PATH, DEFAULT_IMPORT_LIMIT)

    # Run service
    batch_scraper = BatchScraperService(api_key=api_key)
    batch_result = await batch_scraper.scrape_domains(domains)

    # Display and save
    for result in batch_result.results:
        display_result(result)
    batch_scraper.save_results(batch_result.results, Path(OUTPUT_FILE))
```
