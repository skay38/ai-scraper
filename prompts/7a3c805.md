## Implementation

### 1. lint-format.sh (New)

Replaces format.sh. Runs both ruff format and ruff check --fix on Python files after Write/Edit.

### 2. pre-commit.sh (Fixed)

- Added `json_escape()` helper using Python for proper JSON string escaping
- Fixed "no tests" edge case (exit code 5 or "collected 0 items" now allowed)

### 3. check-quality.sh (New)

PostToolUse hook that detects guideline violations:
- `print()` statements → warns to use logger
- Generic exceptions (Exception, ValueError, etc.) → warns to use custom exceptions
- Functions without return type annotations
- Untyped empty collections (`x = []` without type hint)

### 4. Stop Hook (Changed)

**Before:** Prompt-based (just guesses based on prompt text)

**After:** Agent-based (can actually read transcript and verify):
```
type: agent
prompt: Review session, suggest /test, /test-gen, /simplify, /review as needed
```
